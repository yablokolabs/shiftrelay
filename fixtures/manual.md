# P-series Label Printer Field Manual (synthetic)

Document: P-SERIES-FSM-2026.03
Applies to: P100 and P109 label printers.
This is a synthetic training manual. It contains no customer data.

## Safe diagnostics

1. Confirm the printer model from the rear service label.
2. Record the installed firmware from Settings > Device Info.
3. Print the built-in test pattern and keep the sample.
4. Check that media and ribbon are loaded to the diagram on the inner door.
5. Do not open the fuser or cutter while the printer is hot or moving.

## P100: faint or uneven print

Check media type, ribbon tension, and print-head cleanliness. Run the built-in
print-head cleaning cycle. If faint print continues, collect the test pattern,
firmware version, page count, and ambient temperature, then escalate to the
next shift. Do not adjust fuser pressure without a technician-approved fix for
the exact firmware version.

## P100: media roller slip

Clean the roller with the approved lint-free method. Inspect for glazing. If
slip continues on the second pass, record the media lot and escalate.

## P109: cutter jam

Power down, clear the cutter path, and remove debris with the approved tool.
If jams repeat after 200 sheets, record the sheet count and escalate.

## Escalation

Attach the test pattern, firmware version, model, page count, and the steps
already tried. Never apply a fix whose model, firmware, or prerequisites do not
match the current case.
